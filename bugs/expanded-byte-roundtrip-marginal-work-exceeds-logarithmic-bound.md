# Expanded byte round-trip marginal work exceeds its logarithmic bound

Soundness: not soundness. Both expanded byte-copy proofs still verify. Their
extra-copy cost exceeds the existing deterministic-work contract; no false
claim acceptance was observed.

Reproduced on production master `67a990f30b00941cf1f7d7e270a7bcdd57e70230`
(test tree `3fa7a376372ba92954a6629de0742501a02a5ea6`), Rust 1.98.1, ordinary
unoptimized test profile. This test body is unchanged between those commits:

```sh
RUST_MIN_STACK=8388608 cargo test --lib \
  surface::tests::scaling_tests::expanded_roundtrip_extra_copy_is_logarithmic_beside_unrelated_allocations \
  -- --exact --ignored --nocapture
```

The complete original byte-representation program is generated by
`roundtrip_with_unrelated_allocations`. Each unrelated heap allocation has its
null check, writes, failure-path cleanup, and final cleanup. The fixture copies
a record containing a pointer through a byte buffer, then reads the restored
record. At each unrelated-allocation count it expands and cold-verifies both
the original copy sequence and one with an extra fixed `memcpy`.

The unchanged test in `src/scaling_tests/surface/tests/scaling_tests.rs` reports:

```text
unrelated allocations: [1, 2, 4, 7]
extra-copy marginal work: [6017, 6020, 6024, 6030]
operation proof completion: [17, 18, 18, 18]
operation proof context finishing: [301, 302, 302, 302]
simple tactic step: [5675, 5677, 5681, 5687]
```

At seven allocations the permitted marginal is
`6017 + 4 * log2(7) = 6028.22941968823`, below the observed 6030. The growing
simple-step contribution appears to visit unrelated state for the extra copy.
This is a failed pre-optimization baseline, excluded from test-saving totals.

Acceptance criteria:

- Restore the existing test without relaxing its logarithmic guard, removing
  allocation sizes, or rewriting the native C source pattern.
- Identify and eliminate the unrelated-state work in the extra copy, rather
  than merely decreasing its fixed cost.
- Keep all expansion and independent cold-verification checks, pointer-value
  preservation, and the companion whole-work-per-source-byte regression.

Confirmed again on upstream `465b0af319e98541134378a0aee81aa938b72572`; the same work values and assertion failure persist after the independent pointer-offset and call-requirement fixes.
